发布判定：[Release Readiness](../execution/QA-2026-08-21-closure/release-readiness.md) — **PASS_WITH_DEFECT / READY_WITH_MINOR_DEFECTS**，已推 `main`。

### 1.2 当前版本明确限制

- **单城市**自由行（无跨城市联程规划）。
- **中国境内** Provider（高德、QWeather）；真实 Provider 需配置 Key，默认 DEMO 模式。
- **manual-edit TRANSIT** 仍使用 DEMO/local estimate（planner 生成的 TRANSIT 已是真实 AMAP）。
- 请求模型（TAXI/AUTO）与持久化模型（WALKING/TRANSIT/DRIVING）严格区分，wire 层拒绝 TAXI/AUTO。
- 本地优先运行，**未部署公网**，不代表生产环境状态。
- 已知 Minor：A9（F7 per-key 锁理论 GC 竞态，未复现，观察项）、3 个可选真实 AMap 单测保留 skip。

## 2. 下一版本计划

按 [系统未来方向与验收标准](系统未来方向与验收标准.md) §2.2/§2.3 既定顺序推进（进入前须新建批次计划并过独立验收）：

1. **manual edit TRANSIT 真实化**：接入 `candidate-validation → AMap TRANSIT → completion → Java version` 闭环。
2. **D1 polyline 硬化复核**：`_amap_transit_models.py` 非空畸形数组 fail-closed。
3. **模式语义收敛复核**：TAXI/AUTO/DRIVING 在编辑、版本、分享、导出、PDF/ICS 全渠道一致。
4. **跨城/跨区域 TRANSIT** 降级策略。
5. **后续改进**：Java 结构化日志与 traceId、拆分超大服务与页面（`ItineraryService` / `TripDetail.vue`）、浏览器级 SSE 恢复与异常旅程、扩展城市知识、LLM 文案润色（只增强表达，不参与硬事实判定）。

## 3. 明确不属于当前版本

以下能力**当前明确不属于** v1 范围，进入前须新建 plan 并过独立验收（详见验收标准 §2.3）：

- Road / Taxi / Self-driving 完整语义（`ROAD`、`SELF_DRIVING` 等枚举与持久化模型，不引入 completion v12）。
- 用户交通偏好（换乘少/时间短/票价低）与 ordered-rule 重新校准。
- 天气/行李输入、跨 mode 票价 vs 过路费比较。
- Feasibility override / mode oscillation 治理。
- 全局 mode 优化（OR-Tools 级跨 leg 联合优化）。
- 共享/协作者权限、多用户协作。
- 公网部署、生产级多租户/高可用/自动扩缩容（本地优先）。
