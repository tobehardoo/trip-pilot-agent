## 2. 选型取舍（三问纪律，详见批次计划）

**不引入** LangGraph 原生 `interrupt()`（WAITING_USER 恒为干净停等点，域级停等已交付验收行为）、**不引入** Redis 后端（PG 时间戳即可表达 TTL 语义，零新基建）、**不做**后台清扫（惰性过期，语义完整）。路线图"Redis/PG backend"表述中的 PG 分支已满足。

## 3. 测试证据
