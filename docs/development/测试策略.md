## 测试门禁标准

- **零失败**：所有测试套件必须通过，无异常测试减少。
- **覆盖率不下降**：Java JaCoCo ≥80%、Python ≥80%、Web 语句 ≥90%。
- **关键场景必须存在**：异步规划全链路、编辑幂等、版本回滚、分享、导出等必须有测试覆盖。
- **契约测试**：跨语言 JSON Schema 校验必须通过。

## 真实 Provider 测试

真实 Provider 测试默认不运行，避免消耗 API 配额。启用方式：

```powershell
$env:RUN_REAL_PROVIDER_TESTS="true"
uv run pytest
```

真实 Provider 测试必须显式设置环境变量，普通 CI 运行不会消耗 AMap 配额。

## 旅行真实性验收矩阵（规划）

本节规划未来的 golden scenarios 与跨层验证类别，作为后续实施的验收依据；不绑定具体测试实现。权威口径见[行程真实性与旅行骨架](../architecture/行程真实性与旅行骨架.md)。

### Golden Scenarios

| 场景 | 验收意图 | 涉及层 |
| --- | --- | --- |
| 单日游 | 到达→活动/餐饮/交通→离开；无过夜不强制住宿 | Python 规划 + Java 持久化 |
| 多日游 | 首日到达住宿、普通日往返住宿、末日去 Departure | Python 规划 |
| 第一天晚到 | 首日窗口收缩，容量不足不强塞景点 | Python 规划 |
| 最后一天早离开 | 末日 Departure 优先于活动数量 | Python 规划 |
| 无酒店 | 住宿语义节点仍存在，跨日连续可证明 | Python 规划 + 版本模型 |
| 区域住宿 | 区域估算锚点清晰标记估算，不伪造酒店 POI | Python 规划 |
| 重复 POI | 景点跨日重复被拒绝或修复 | Python 规划 + Hard Validation |
| 餐饮 | 默认用餐时间保留；显式餐饮窗口为硬约束 | Python 规划 |
| 时长 | 时长越界为硬错误；接近 recommended 为体验加分 | Hard Validation + Evaluation |
| N/A | 无预算/无兴趣时 N/A 显式展示，总分归一化 | Evaluation + Web 展示 |
| 修复循环 | 硬校验失败进入有界修复/重规划，而非伪成功 | Python 规划 |
| 完成进度 | 进度停留 95% 后由完成事件收尾，终态覆盖进度态 | Worker + Java + Web |

### 跨层验证类别

- **Python 规划层**：骨架构建、跨日去重、住宿状态、时长画像、校验与修复的单元/集成场景。
- **契约层**：completion v8 的可选日程字段（`dayType`/`kind`/`timeFixed`）在 Pydantic 与 Java 消费者间的跨语言解析一致性。
- **Java 持久化层**：验证结果元数据、完成事务与不可变版本的绑定；失败事件不产生版本。
- **Web 展示层**：可执行性（已验证/待修复）与体验评分双层展示；N/A 显示"未适用"；终态后停止播放进度。

## 已知测试限制

- 浏览器验收覆盖 SSE 恢复与核心组合链路，但不替代真实 Provider、浏览器域名/CSP 和故障注入验收。
- 真实公交路线未纳入测试。
- Windows 本地 Maven 需显式指定 ASCII JaCoCo 数据路径；Linux CI 不受影响。
- Windows 上的 pytest 临时目录可能存在历史权限污染，建议使用明确隔离的临时目录。

## CI（GitHub Actions）

远端 CI 包含五个 Job：

| Job | 内容 |
| --- | --- |
| `java` | Maven verify、Flyway、JaCoCo |
| `python` | pytest、Ruff、benchmark、覆盖率 |
| `web` | Vitest、vue-tsc、build、Playwright |
| `infrastructure` | Compose config、镜像构建、Compose smoke、API 探测 |
| `repository-safety` | gitleaks 历史扫描、Markdown links、diff check |

所有五项必须通过，才有远端 CI 验证的 RC 候选资格。
