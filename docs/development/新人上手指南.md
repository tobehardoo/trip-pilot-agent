# 新人上手指南

- 文档状态：生效中
- 最后更新：2026-08-29

## 1. 项目是什么

TripPilot 是约束驱动的旅行规划平台：行程不是"看起来合理"，而是时间、交通、预算上**真正可执行**。当前主线是 Agent 化改造（v1.1）——LLM 负责决策，确定性代码负责守门。

## 2. 顶层目录

| 目录 | 内容 |
|---|---|
| `apps/agent-service/` | Python 3.12 · FastAPI · LangGraph · OR-Tools（Agent + 规划） |
| `apps/travel-server/` | Java 21 · Spring Boot · MyBatis（业务权威） |
| `apps/web/` | Vue 3 · TypeScript · Vite |
| `contracts/` | 事件契约 JSON Schema（权威） |
| `docs/` | 文档中心（架构 / 契约 / 路线 / ADR） |
| `infra/` `scripts/` `test-results/` | 基础设施、脚本、测试结果 |

## 3. 核心链路

```
用户 → Java API → Outbox → RabbitMQ → Python Worker → Agent/Planning
  → OR-Tools 求解 → 可行性校验 → 事件回写 → Java 持久化 → SSE
```

## 4. agent-service 模块速览（src/trip_agent/）

| 模块 | 职责 |
|---|---|
| `agent/` | Agent 编排层：约束槽位、工具、LangGraph 循环（**新，重点看**） |
| `worker/` | AMQP 消费、命令处理（`processor.py`）、契约、进度 |
| `feasibility/` | 可行性校验、有界修复（守门） |
| `planning/` | 逐日调度、模式推荐、候选 |
| `providers/` | 高德 / Demo Provider、重试、缓存 |
| `guide_intelligence/` | 攻略情报、营业时间、OCR、城市事实 |
| `retrieval/` | pgvector 知识检索 |

## 5. 快速上手五步

1. 读 [文档中心](../index.md) 与 [系统架构](../architecture/系统架构.md)。
2. 按 [本地运行指南](../operations/本地运行指南.md) 起全栈（无 Key 用 DEMO_ONLY）。
3. 读 [Agent化路线图](../product/Agent化路线图.md)，了解当前主线的缺陷清单（D1–D5）。
4. 跑测试：Python `pytest --basetemp=.pytest_tmp_x`（Windows 必须指定 basetemp）；Java `mvn verify`；Web `pnpm test`。
5. 改代码前先看对应模块的既有测试风格（如 `tests/agent/` 用 `run_async` 包裹协程）。

## 6. 常见约定

- 测试：不用 pytest-asyncio，异步用例用 `platform_util.run_async`。
- 契约：改事件必须同步 JSON Schema、Java、Python、TypeScript（ADR-014）。
- 质量：RED → GREEN → 回归 → 证据落盘；fail-closed 优先。
