## 2. 测试证据

- 工具语义 7 测（fake store）：PENDING 落库、无 evidence 拒绝确认、有 evidence 确认、撤销立即生效且同值确认/提案均不复活、未知分类忽略、无身份/无 store fail-closed。
- 真实 PG（一次性容器）：`test_agent_profile.py` 集成 **8/8 全过**（22 项含 persistence），覆盖 PENDING→CONFIRMED→再提案不重置→REVOKED→拒确认→再提案不复活全生命周期；容器销毁。
- 全量回归：**1866 passed / 42 skipped / 0 failed**（基线 1854 不降）；ruff 全绿。

## 3. 设计发现

- **偏好 value 必须存用户原话**（如「松弛」）：英文枚举值永远过不了 evidence-match——测试先行暴露了这一契约约束，确立了"value 自由文本 + category 枚举"的存储形态。
- Java 侧确认 UX/端点与 userId 传递归 P2.8（触发端点一并实现）。
