## 3. 过程中发现并修正的问题

- **空白文本规则跨语言不一致**（RED 测试抓到）：JSON Schema/pydantic 的 `minLength 1` 放行 `"  "`，而 Java `validText` 按 `isBlank` 拒绝。统一为两侧都要求至少一个非空白字符（schema/pydantic 加 `pattern \S`）。
- Java 测试环境两处与既有测试对齐：`ObjectMapper.findAndRegisterModules()`（OffsetDateTime 需要 JavaTimeModule，缺失时 4 个合法用例报错、拒绝用例因 Jackson 日期异常假阳性通过——已修正后按真实校验逻辑通过）、`StandardCharsets.UTF_8`（中文断言）。
