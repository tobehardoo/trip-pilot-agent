### 1.2 核心行为变更（用户可感知）

1. **终态不再黑洞**：run 上限触顶、等待过期、resume 被拒、纯文本回答——过去全部静默（前端永远"思考中"），现在都有 `AGENT_RUN_FINISHED` 事件并渲染为错误恢复卡/答复气泡。
2. **工具名不再上屏**：`update_constraints` 等 9 个工具名映射为业务语言（"理解旅行需求"等），未知名兜底"处理旅行事务"；单测与 e2e 均断言内部名不出现在 DOM。
3. **阶段只由真实事件驱动**：时间线/阶段条按 `AGENT_STEP` 的 tool 相位聚合，没有事件就没有阶段（反 Fake Progress 有测试钉死）。
4. **澄清卡按 `expectedType` 结构化应答**：CHOICE 单选直发、DATE 日期选择、NUMBER 数字输入、TEXT 快捷 chips+自由文本；应答后卡片锁定；WAITING_USER 常驻横幅。
5. **修复 apply 真 bug**：应用约束现发送完整基线 + 乐观锁 `version`（旧代码缺 version 且会清空未列字段）。
6. **错误文案全部用户语言**：`AGENT_DIALOGUE_UNAVAILABLE`（原"Agent dialog service rejected the request"）等按 code 映射，未映射错误落兜底并只进控制台。

## 4. 真实栈端到端 Agent 冒烟（维度 7 明细）

| 步骤 | 观测 |

## 7. 结论

- 方案 → 实现 → 推送 → 重启 → 验证闭环完成，**3025 个自动化测试（1878+618+523）+ 6 项 e2e 场景 + 真实栈对话冒烟全部通过**。
