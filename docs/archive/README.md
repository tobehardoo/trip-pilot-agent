## 使用规则

- 需要判断当前能力、接口、部署或发布状态时，回到上一级维护文档。
- 需要追溯为什么某个方案曾被提出或某次验收如何执行时，再阅读本目录。
- 新的阶段性报告可以放入本目录，但应在 [发布状态](../release.md) 中保留简短索引。
