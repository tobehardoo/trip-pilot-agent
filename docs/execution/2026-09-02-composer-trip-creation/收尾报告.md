## 4. 环境备注（复现测试所需）

- pytest 必须带 `--basetemp`（本机 `C:\Windows\Temp\pytest-of-*` ACL 损坏会导致
  11 个 tmp_path 用例 ERROR；`--basetemp=.tmp/pytest` 全绿，`.tmp/` 已在 gitignore）。
- 本机 npm/pnpm 全局 shim 损坏（路径错乱）：Web 侧用 `./node_modules/.bin/*` 直跑。
- 4173 端口在保留段（EACCES），e2e 用 `PLAYWRIGHT_WEB_PORT=5173`。
- Java 走 `JAVA_HOME=BellSoft Liberica JDK 21`（PATH 上的 java 1.8 与项目无关）。
