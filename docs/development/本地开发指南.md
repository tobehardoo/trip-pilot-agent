# 本地开发指南

- 文档状态：生效中
- 最后更新：2026-08-29

## 1. 仓库结构

```
apps/
├── agent-service/    # Python 3.12 · FastAPI · LangGraph · OR-Tools（Agent + 规划）
│   └── src/trip_agent/
│       ├── agent/            # Agent 编排层（state / tools / graph）
│       ├── feasibility/      # 可行性校验与有界修复
│       ├── guide_intelligence/ # 攻略情报、营业时间、OCR、城市事实
│       ├── planning/         # 逐日调度、模式推荐、候选
│       ├── providers/        # 高德 / Demo Provider、重试、缓存
│       ├── retrieval/        # pgvector 知识检索
│       └── worker/           # AMQP 消费、命令处理、契约、进度
├── travel-server/    # Java 21 · Spring Boot · MyBatis（业务权威）
└── web/              # Vue 3 · TypeScript · Vite
contracts/            # 事件契约 JSON Schema（权威）
infra/ docs/ scripts/ test-results/
```

## 2. 本地启动

```bash
# 全栈（推荐）
docker compose -f compose.prod.yaml --env-file .env up -d --build --wait --wait-timeout 240
# Web: http://127.0.0.1:8080

# 无真实 Key 时保持 PROVIDER_MODE=DEMO_ONLY 即可跑通主流程
```

## 3. Python（agent-service）

```bash
cd apps/agent-service
uv sync                  # 安装依赖（含 langgraph）
./.venv/Scripts/python.exe -m pytest -q --basetemp=.pytest_tmp_x   # 跑测试
./.venv/Scripts/python.exe -m ruff check src tests                 # lint
```

**注意**：本机 `C:\Windows\Temp` 权限不足会导致 11 个依赖 `tmp_path` 的用例报 error，
必须指定可写 basetemp（如上），且 basetemp 目录不要复用。

## 4. Java（travel-server）

```bash
cd apps/travel-server
mvn verify    # 558 测试 + JaCoCo 覆盖率门禁（≥80%）
```

## 5. Web

```bash
cd apps/web
pnpm install && pnpm test && pnpm typecheck && pnpm build
```
