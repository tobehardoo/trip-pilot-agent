## 3. 验收标准

- 三轮对话全链路测试（fake repository/publisher + 脚本决策器）：start → 问城市 → resume 确认 → 问日期 → resume 确认 → 答复 COMPLETED；证明 checkpoint 跨回合恢复、user_message 注入、事件线型（大写枚举）、轨迹续号与幂等。
- 重复 AGENT_START（同 eventId）→ 幂等跳过，不产生第二 run。
- 未知 run / 非 WAITING_USER 的 resume → 拒绝（不 ack）。
- amqp 分发：合法命令 ack、非法命令 reject、planning 命令不受影响（既有 test_amqp_worker 全绿）。
- 全量基线 **1816 passed 不降**，ruff 全绿。
- resume 重复投递语义落地：worker 状态守卫 + 消费方 eventId 查重（批次 C 决策的细化，记入验收报告）。
