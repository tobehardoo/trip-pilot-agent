## 3. 7a 实现期发现并修正的问题

- **stream 首帧是输入态**：values 模式的首个 yield 携带回合继承的全部观测，cursor 从 0 起会把上一回合观测重发为 STEP——改为以回合起始观测数为基线。
- **ask_user 工具观测与问题事件重复**：按克制决策过滤出 STEP 流（批次计划已记录）。
- 事件序列按真实语义对齐：第三回合的 `update_constraints`（确认日期）本身也是工具步。
