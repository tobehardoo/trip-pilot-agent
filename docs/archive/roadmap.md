## 当前基线：V1.3

V1.3 已建立可信城市情报、不可变规划上下文、事实影响解释以及行程版本列表、差异和幂等
回滚的代码与测试基线。其已实现范围、实际测试结果和已知限制保留在
[V1.3 系统状态与交接](28-current-system-status-and-v1-4-plan.md) 与
[V1.3 发布验收清单](release-checklist.md)。

真实高德 Web JS 底图仍必须由部署者在有效 Key、安全密钥和域名白名单环境中完成验收；无
凭据或 Provider 故障时，系统只能展示明确标识的路线概览或降级结果，不能将其描述为真实
底图或实时 Provider 成功。

## 当前发布目标：V2.0

V2.0 的主题是“可观测、可交付、可持续使用的智能旅行规划产品”。它将 V1.3 的能力从可用
工程链路推进为可由真实用户顺畅完成的规划、调整、查看、分享和恢复流程。

### P0：必须完成

- V1.3 基线收口、标签、迁移/契约/Compose 验收和发布证据。
- Vue Router、Pinia、`App.vue` 职责收敛、页面路由化和统一页面状态。
- Worker 到 SSE 的真实规划阶段进度、重连恢复、取消/失败状态和阶段指标。
- 通勤段后端写回、影响预览、时间/费用/冲突重算与不可变版本差异。
- 四条独立、可重复执行的浏览器 E2E 用户旅程。
- 规划、队列、Provider、城市情报指标，结构化日志和受保护故障诊断。

### P1：重要产品能力

- 旅行列表搜索、筛选、分页和归档。
- 指向不可变行程版本的安全只读分享链接。
- 可打印 PDF 与标准 ICS 日历导出。
- 手机浏览器的只读旅行体验。

### P2：P0 和 P1 后再评估

- 更多城市模板、来源管理 UI、多主题、多方案比较和更精细 POI 过滤。
- 预算/节奏模式、结果评分、用户反馈与简单使用统计。

## 明确不做

V2.0 不做国际化、多人实时协作、支付或真实预订、Kubernetes、完整 PWA、全面 UI 重构、
多城市联程、新微服务、新数据库、新消息中间件或大规模城市/爬虫扩展。这些能力不能抢占
现有规划闭环的稳定性、真实性和可维护性。

## 历史版本

V1.2 的核心范围为结构化约束、异步规划、真实与 Demo Provider、候选过滤、OR-Tools 求解、
攻略情报、活动编辑、地图时间轴和基础部署运维。V1.3 在此基础上完成可信城市事实、快照、
解释和可恢复版本。历史发布记录不因为 V2 规划而变成 V2 已实现能力。
