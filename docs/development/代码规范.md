# 代码规范

- 文档状态：生效中
- 负责模块：全部
- 最后更新：2026-08-05
- 当前事实来源：是

## 通用原则

- 使用 UTF-8 编码。
- 使用 LF 行尾符（跨平台一致）。
- 提交前确保静态检查通过。
- 不提交密钥、Token、Cookie 或真实凭据。

## Java

### 技术选型

- Spring Boot 作为业务后端框架。
- MyBatis 而非 JPA：复杂查询、Flyway 迁移和 PostgreSQL 特性使用显式 SQL。
- Flyway 管理数据库迁移，版本号格式 `V<序号>__<描述>.sql`。

### 编码约定

- 遵循标准 Java 命名约定。
- Service 层负责事务编排，Repository 层负责数据访问。
- 数据库迁移只向前，不修改已发布迁移。
- 所有用户数据按所有权校验隔离。
- 日志不包含 Token、Cookie、Provider Key、模型 Key 或完整攻略正文。

### 关键类

| 类 | 职责 |
| --- | --- |
| `ItineraryService` | 行程版本管理、编辑、差异（注意：超过 1100 行，需要拆分） |
| `PlanningTaskService` | 规划任务创建、状态管理、evaluation 读取 |
| `ItineraryVersionService` | 版本列表、回滚 |
| `PlanningCompletedEventParser` | 完成事件解析（接受 v1–v6 历史只读与 v8，拒绝 v7） |

## Python

### 技术选型

- FastAPI 用于 Agent API。
- OR-Tools 是规划优化依赖；当前主路径为逐日贪心填充，全局求解是目标（见[规划工作流](../architecture/规划工作流.md)）。
- Pydantic 用于 Schema 校验。
- Ruff 用于代码格式和静态检查。

### 编码约定

- 遵循 PEP 8 风格，由 Ruff 强制执行。
- 使用 type hints。
- Worker 只消费冻结输入，不直接修改用户业务表。
- 日志不包含密钥、授权数据、完整 Provider 响应或堆栈。

### 关键模块

| 模块 | 职责 |
| --- | --- |
| `trip_agent.worker` | 消息消费、规划执行、事件发布 |
| `trip_agent.infrastructure.amap` | 高德 Provider 实现 |
| `trip_agent.infrastructure.demo` | Demo Provider 实现 |
| `trip_agent.evaluation` | PlanEvaluator 评分规则 |
| `trip_agent.guide_intelligence` | 攻略抽取 |

## TypeScript / Vue 3

### 技术选型

- Vue 3 Composition API。
- Vite 构建工具。
- Vitest 单元测试。
- Playwright 浏览器 E2E。
- vue-tsc 类型检查。

### 编码约定

- 使用 TypeScript 严格模式。
- 组件使用 `<script setup>` 语法。
- 所有 API 调用需处理 loading、error、empty 状态。
- 用户可见文本使用简体中文。
- API 返回的 `provider` 和 `estimated` 字段必须正确展示。

### 关键组件

| 组件 | 职责 |
| --- | --- |
| `TripWorkspace.vue` | 工作区入口，管理 itinerary version 和 evaluation 状态 |
| `TripDetail.vue` | 行程详情，包含 PlanEvaluation 面板、天气时间轴、地图（注意：超过 1300 行，需要拆分） |
| `PlanEvaluationPanel.vue` | 方案评估面板 |
| `WeatherTimeline.vue` | 天气时间轴 |

## 跨语言契约

- 跨语言契约变更必须同步 JSON Schema、Java、Python、TypeScript 和示例消息。
- 契约文件位于 `contracts/messaging/`。
- JSON Schema 使用共享 fixtures，Python 和 Java 测试消费同一文件。
- 新增可选字段保持向后兼容，删除必填字段需要升级主版本。

## 数据库迁移

- 迁移文件位于 `apps/travel-server/src/main/resources/db/migration/`。
- 命名格式：`V<序号>__<描述>.sql`。
- 只向前迁移，不修改已发布迁移。
- 当前最新版本：V27。

## Git 约定

- 提交信息使用中文或英文，保持一致。
- 文档提交使用 `docs:` 前缀。
- 不提交 `.claude/`、`.pnpm-store/`、构建产物、测试缓存、私有 env 或密钥文件。
- 提交前运行 `git diff --check` 确认无空白问题。
