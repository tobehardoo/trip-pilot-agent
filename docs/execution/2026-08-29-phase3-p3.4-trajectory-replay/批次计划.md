## 1. 设计

- `benchmarks/agent_trajectory/run_agent_trajectory.py`：场景驱动的确定性回放——每场景 = 用户消息序列 + 统一确定性策略决策器（消息含确认语义 → evidence-match 确认 → build → validate），跑 `AgentDialogProcessor`（FakeRepository + 真实 DemoItineraryBuilder + 真实 StructuralFeasibilityGate，无 Key）。
- 场景（首发 5 个）：happy-path-emit、clarification-loop（含糊回答→有界追问）、rejected-value（否定后同值不复活）、infeasible-must-visit（结构化失败、不发射）、boundary-dates（7 天边界）。
- 不变量断言：stop_reason ∈ {WAITING_USER, EMITTED}（无 FAILED）、步数/工具/LLM 三重上限、事件序列形状、EMITTED 时 itinerary 可重构且过守门、FAILED 观测不冒泡。
- pytest 接入：`tests/test_benchmark_agent_trajectory.py` 调 runner 全场景（无 DB、无 Key）。

## 2. 验收标准

- 全量基线不降。
