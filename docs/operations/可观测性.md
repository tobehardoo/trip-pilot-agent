## 概述

TripPilot 的可观测性体系包括 Prometheus 指标、结构化日志、健康检查和诊断入口。

## 健康检查

### 服务健康端点

| 服务 | 端点 | 说明 |
| --- | --- | --- |
| Java API | `GET /api/health` | 数据库、Redis、RabbitMQ 连通性 |
| Agent API | `GET /health` | Python 服务存活 |
| Web | `GET /` | Nginx 静态服务 |
| Prometheus | `GET /-/healthy` | Prometheus 存活 |

### Compose 健康检查

所有长期运行服务均配置 Docker healthcheck：

- PostgreSQL：`pg_isready`
- Redis：`redis-cli ping`
- RabbitMQ：`rabbitmq-diagnostics check_port_connectivity`
- Java、Agent API、Worker、Web、Prometheus：HTTP 健康端点

`knowledge-init` 是一次性任务，退出码为 0 表示成功。

## Prometheus 指标

### 业务指标

| 指标 | 说明 |
| --- | --- |
| 规划成功/失败/取消计数 | 按 Provider 模式、结果类型分组 |
| 阶段耗时 | 每个规划阶段的耗时分布 |
| Provider 结果 | 按 Provider、操作类型、结果分组 |
| 任务结果 | 按终态类型分组 |

### 基础设施指标

| 指标 | 说明 |
| --- | --- |
| RabbitMQ 队列积压 | 各队列的 ready、unacked 消息数 |
| JVM 指标 | 堆内存、GC、线程 |
| HTTP 请求 | 延迟、状态码分布 |

### 访问方式

Prometheus 默认端口 `9090`（可通过 `PROMETHEUS_PORT` 调整）。

## 日志规范

### 日志级别

| 级别 | 使用场景 |
| --- | --- |
| ERROR | 需要人工介入的故障：Provider 不可用、数据库连接失败、消息消费异常 |
| WARN | 可恢复的降级：Provider 回退、重试、配额接近上限 |
| INFO | 关键业务事件：任务创建、完成、失败、取消、版本创建 |
| DEBUG | 开发调试信息 |

### 关键日志字段

日志必须携带以下非敏感标识：

- `traceId`：请求追踪 ID
- `tripId`：旅行 ID
- `taskId`：规划任务 ID
- `messageId`：消息 ID
- `provider`：Provider 名称

### Provider 回退日志

使用稳定标记 `planning_provider_fallback`，并记录：

- `operation`：操作类型
- `reason`：回退原因
- `retry_count`：重试次数
- `event_id`：关联事件 ID
- `trace_id`、`task_id`、`trip_id`

### 禁止记录的内容

以下内容**不得**进入日志：

- 密钥（`AMAP_WEB_SERVICE_KEY`、`JWT_SECRET` 等）
- Token（JWT、Cookie、Authorization）
- 完整 Provider 请求/响应
- 用户敏感数据
- 堆栈跟踪中的敏感信息
- 完整攻略正文

## 诊断入口

### 内部诊断 API

受 `INTERNAL_DIAGNOSTICS_TOKEN` 保护：

- 查看失败任务的脱敏上下文。
- 对安全失败的任务执行幂等重试。

诊断入口只暴露脱敏上下文，不暴露 Token、Key、完整 Payload 或用户数据。

### 死信队列

RabbitMQ 死信队列保留无法消费的消息，用于排查消息格式错误或消费者异常。

## 告警

### 建议告警规则（阶段 4 staging 验收时配置）

| 告警 | 条件 | 严重级别 |
| --- | --- | --- |
| 规划持续失败 | 5 分钟内失败率 > 50% | Critical |
| Provider 不可用 | `REAL_ONLY` 下 Provider 全部失败 | Critical |
| 队列积压 | 队列 ready 消息持续增长 | Warning |
| 服务下线 | 健康检查连续失败 | Critical |
| 数据库连接池耗尽 | 活跃连接 > 80% | Warning |
| 磁盘空间 | 使用率 > 85% | Warning |

当前告警配置尚未在 staging 环境验证。
