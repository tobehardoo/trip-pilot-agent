## 1. 三项选型取舍（三问纪律，记录在案）

| 候选 | 决策 | 理由 |
| --- | --- | --- |
| LangGraph 原生 `interrupt()` | **不引入** | 当前拓扑里 WAITING_USER 永远是干净停等点，域级停等 + 续跑已交付验收行为；interrupt() 只会省一次 resume 后的重新决策——而那次决策正是 LLM 带着答案看全局的合理行为。不解决实际问题，不加。 |

## 3. 验收标准

- 过期 WAITING_USER：resume 被拒（RUN_EXPIRED），run 状态落 EXPIRED，不产生新执行。
- 僵死 RUNNING（checkpoint 超 STALE 阈值）：resume 触发崩溃恢复，从最后 checkpoint 续跑到收敛。
- 新鲜 RUNNING：拒绝（RUN_IN_PROGRESS），防双执行。
- 未过期 WAITING_USER 续跑行为与既有 E2E 一致。
- 「行程版本单调递增」验收条款：agent 路径的发射物当前不建 Java 版本行（P2.8 后接 planning 版本链，由确定性管线保证单调）——本条款**移交 P2.8/规划集成**，非本批可交付，记录在案。
