# 产品路线图

> 当前完整度评分和详细需求以 [产品完整度与需求基线](27-product-completeness-and-requirements-baseline.md) 为准。

## 已发布基线（V1.2 发布候选）

已完成一条可部署的端到端链路：

- 用户注册、登录和会话管理
- 创建单城市旅行并定义结构化约束
- 异步规划、SSE 进度展示和任务取消
- 真实高德 POI 和路线，Demo 模式降级
- 候选过滤、偏好排序和 OR-Tools 硬约束求解
- 不可行规划的结构化冲突原因和放宽建议
- 广州城市知识导入、pgvector 检索和来源证据
- 攻略情报导入和管理
- 活动删除、移动、锁定和局部重规划
- Vue 地图、时间轴联动和 SSE 进度
- Docker Compose、Prometheus、CI 和备份恢复

V1.2 的范围是把 `TP-REQ-001` 至 `TP-REQ-004` 交付为稳定、可复现的发布候选。
发布证据以 [V1.2 发布验收清单](release-checklist.md) 为准，不再用主观百分比代替验收结果。

### V1.2 已知边界

- 当前分支已在 V1.2 之上增加 TXT/Markdown、粘贴正文、小红书分享正文、手动高德城市
  同步与日期级雨天排序，但这些只是 V1.3 的已完成基线，不等于 V1.3 完成。
- 广州官方知识目前是静态来源注册与导入，不包含按目的地自动发现、实时天气或景点
  门票/营业/预约统一核验。
- 高德 SDK、路线和 Marker 已加载；本机底图仍需完成 Web JS Key 域名授权验证。

## 当前发布目标（V1.3 — 可信城市情报与可恢复版本）

- ✅ 行程版本列表、差异和幂等回滚（TP-REQ-005）
- ✅ 广州、北京、上海官方来源，自动预热、TTL 刷新和 stale 降级（TP-REQ-006）
- ✅ 攻略重新核验和来源审核/启停管理（TP-REQ-007）
- ✅ URL、正文、TXT/Markdown 和小红书分享正文统一导入；规则与受限结构化模型抽取、
  字段校验和来源冲突解释（TP-REQ-019）
- ✅ 规则 + 结构化模型事实抽取、证据跨度校验和拒绝原因
- ✅ 官方事实与社区事实分级进入不可变规划上下文并输出影响解释
- ⛔ 地图无凭据/超时降级已通过真实浏览器验收；真实底图仍等待部署者配置高德 Web JS
  Key、安全密钥与域名白名单

V1.3 明确非目标：PDF/OCR、登录态平台抓取、全网官网发现、多方案、分享、导出、完整
运营后台、新微服务、Kafka/Kubernetes/工作流引擎和复杂多 Agent。

实施顺序已经完成：文档与迁移 → 来源/规范化/校验/合并 → 自动预热与快照 → Worker
影响记录 → 前端解释与地图 → 版本差异/回滚 → 全量验收。逐项证据见
[V1.3 发布验收清单](release-checklist.md)。

## 生产可运营 V1 退出条件

以下全部完成后，项目才标记为「生产可运营 V1」；它们不是 V1.2 已完成事项：

- 攻略和已核验动态事实进入规划并在结果中可追溯
- 用户可以删除、移动、锁定活动并执行局部重规划
- 用户可以比较和回滚行程版本
- 天气、营业、预约、票价和公共交通有实时核验或明确拒答策略
- 只读分享和至少一种可携带导出形式可用
- 跨服务 E2E、业务指标、告警和恢复演练形成发布证据

## 不做的事情

- 不提供机票、火车票、酒店预订或支付
- 不爬取 12306、携程等平台的受限数据
- 不自动预约景点（只提供提醒）
- V1 不支持自驾、停车、限行和租车
- V1 不支持多城市联程
- V1 不支持多人实时协作编辑
