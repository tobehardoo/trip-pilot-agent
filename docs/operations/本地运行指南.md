# 本地运行指南

- 文档状态：生效中
- 最后更新：2026-08-29

## 1. 前置条件

- Docker Desktop / Docker Engine + Compose v2（建议至少 8 GB 内存）
- 本地开发（可选）：JDK 21、Python 3.12+、Node.js + pnpm

## 2. 配置

```bash
cp .env.example .env
```

为 `POSTGRES_PASSWORD`、`REDIS_PASSWORD`、`RABBITMQ_PASSWORD`、`JWT_SECRET`、`AGENT_INTERNAL_TOKEN`、`INTERNAL_DIAGNOSTICS_TOKEN` 设置互不相同的本地值。

- **无真实 Key**：保持 `PROVIDER_MODE=DEMO_ONLY` 即可运行完整主流程（确定性 Demo 数据，明确标注）。
- **真实数据**：设置 `PROVIDER_MODE=REAL_ONLY`（或 `REAL_WITH_EXPLICIT_FALLBACK`），填入 `AMAP_WEB_SERVICE_KEY`、`QWEATHER_API_KEY`、`VITE_AMAP_WEB_JS_KEY` + `VITE_AMAP_SECURITY_CODE`。
- 缺失关键 Key 时 Worker 启动即失败（fail-closed），不会静默降级。
- **LLM（Agent 编排）**：配置 `STRUCTURED_MODEL_ENDPOINT` / `STRUCTURED_MODEL_API_KEY` / `STRUCTURED_MODEL_NAME` 启用模型决策；未配置时 Agent 层走确定性退化（AskingDecider），约束收集仍可工作。

## 3. 启动

```bash
docker compose -f compose.prod.yaml --env-file .env up -d --build --wait --wait-timeout 240
```

- Web：<http://127.0.0.1:8080>（API 经 `/api` 代理）
- Prometheus（可选）：<http://127.0.0.1:9090>

停止：`docker compose -f compose.prod.yaml --env-file .env down`（加 `-v` 删除数据卷）。

## 4. 常用排障

| 现象 | 检查 |
|---|---|
| Worker 启动失败 | `.env` 是否缺失关键 Key（fail-closed 设计） |
| 规划卡 RUNNING | RabbitMQ 连通性、消息是否进死信队列 |
| 结果标注 DEMO | `PROVIDER_MODE` 未配置真实 Key |
| 前端地图空白 | `VITE_AMAP_WEB_JS_KEY` + 安全码未配置 |
| Agent 只提问不规划 | `STRUCTURED_MODEL_*` 未配置，走确定性退化 |
