# V1.3 发布验收清单

> 基线日期：2026-07-26
>
> 发布分支：`codex/complete-v1`
>
> 目标：交付可信城市情报、不可变规划上下文、可解释影响和可恢复行程版本。

## 范围

V1.3 包含三城市可信来源、文档规范化、规则与结构化模型候选、事实校验/合并、自动预热、
TTL/stale 降级、规划影响解释、地图真实底图闭环、版本列表/差异/回滚。PDF/OCR、登录态
平台抓取、全网官网发现、多方案、分享、导出、完整运营后台和跨服务浏览器 E2E 属于非目标。

## 功能退出标准

- [x] 广州、北京、上海存在已审核、可查询、可启停的官方城市与景点来源。
- [x] 创建旅行后通过现有 Outbox/RabbitMQ 异步预热，重复消息幂等。
- [x] 创建规划任务前按类别 TTL 和旅行日期检查，必要时刷新。
- [x] Provider 失败保留最后成功事实并明确标 `stale`；无历史事实仍可降级规划。
- [x] URL、正文、TXT/Markdown、小红书分享正文进入同一规范化端口。
- [x] 中文文本可提取带证据跨度的地址、门票、开放、预约和天气候选。
- [x] 结构化模型严格受 Schema、输入上限、超时和重试上限约束，失败不阻断规则抽取。
- [x] `FactValidator` 与 `FactMerger` 覆盖非法字段、无证据、官方/社区和日期冲突。
- [x] Java 冻结不可变 `PlanningContextSnapshot`；Worker 不实时抓网页或读取业务表。
- [x] 官方新鲜关闭/预约形成硬规则；社区或 stale 事实只影响软提示/排序。
- [x] 雨天只影响对应日期，官方门票与高德参考消费语义分离。
- [x] 结果页显示事实摘要、来源、可靠性、核验时间、适用日期、影响、证据和冲突。
- [x] 地图只有基础图块完成后才显示覆盖物；超时/失败保留路线概览。
- [x] 用户可查看版本列表、结构化差异并幂等回滚。
- [x] 回滚创建新 `ROLLBACK` 版本，不修改或删除历史版本。
