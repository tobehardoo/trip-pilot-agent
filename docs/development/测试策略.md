## 3. 关键纪律

- **RED → GREEN → 回归 → 证据落盘**：每个缺陷先写失败测试，修复后全量回归并留存证据。
- **Fail-closed**：畸形 Provider 响应拒绝而非降级误报；数据不确定时显式 UNKNOWN。
- **Agent 层测试**：项目不使用 pytest-asyncio；异步用例用 `platform_util.run_async` 包裹（`tests/agent/` 为范例）。
- **确定性优先**：规划器、可行性、评估器为纯确定性代码，时间通过可注入 clock。
- **历史事件兼容**：契约测试覆盖旧版本事件读取，新版本不得破坏（ADR-014）。

## 4. 常见坑

- 本机跑 Python 测试必须 `--basetemp=.pytest_tmp_x`（Windows Temp 权限），且目录不复用。
- 真实 Provider 测试默认 skip（需 Key）；`PROVIDER_MODE=DEMO_ONLY` 保证无 Key 全链路可跑。
