## 1. 设计

- `DECISION_SCHEMA` 增可选 `strategy` 枚举：DIRECT / RETRIEVE / CLARIFY / REPLAN（加法扩展，向后兼容）。
- `Decision.strategy` + `AgentState.strategy`：每次决策的显式策略落状态与 checkpoint（轨迹可查）。
- 确定性路径（AskingDecider）：必填槽位缺失 → CLARIFY，齐备 → DIRECT；LLM 路径：prompt 指示模型声明策略，schema 枚举约束，未声明 → None（不猜）。
- 可观测：processor 不因此多发事件（克制）；观测面 = 状态/checkpoint + 本批测试断言。
