## 1. 设计

| 项 | 设计 |
| --- | --- |
| 存储 | `agent.user_travel_profile`（V2 迁移）：(user_id, category, value) 唯一，status ∈ PENDING/CONFIRMED/REVOKED，source_run_id 审计 |
| 分类 | 固定枚举（ADR-015 待定问题的建议选项）：PACE / BUDGET / MOBILITY / DIETARY / AVOID / TRANSPORT / ACCOMMODATION |
| 写入 | 新工具 `update_preferences`：proposals → PENDING；confirmations → **evidence-match 才 CONFIRMED**（与 D5 同一信任规则）；revocations → REVOKED（显式否定立即生效，被 REVOKED 的值再提议不复活——镜像槽位 REJECTED 语义） |
| 注入 | 已确认偏好注入决策 prompt（`AgentState.confirmed_preferences`，处理器在回合开始时装载） |
| 身份 | AGENT_START 契约 v1 增**可选** `userId`（向后兼容的加法扩展，Java 无 START parser，P2.8 发布时携带）；无 userId → profile 工具 fail-closed（PROFILE_UNAVAILABLE） |
| 能力缝 | `ToolRuntime.profile_store`；缺省 fail-closed（CAPABILITY_MISSING） |

## 2. 验收标准

- 提案 → PENDING；确认必须 evidence-match，否则不落 CONFIRMED；撤销立即生效且同值再提案不复活。
- 无 userId / 无 store 能力 → fail-closed；已确认偏好进入决策 prompt。
- PG 迁移与仓库往返经容器验证；全量基线不降。
