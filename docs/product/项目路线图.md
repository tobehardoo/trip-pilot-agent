## 2. 当前方向：Agent 化（v1.1 主线，2026-08-29 启动）

v1.1 主线是把 `agent-service` 从「确定性流水线 + LLM 抽取」升级为真正的 Agent 编排层，核心原则：

- **信任边界**：LLM 负责意图理解、约束收集、策略选择、澄清；调度求解、可行性校验、终态生成归确定性内核，`validate_itinerary` 一票否决。
- **记忆分层**：Working（AgentState + checkpoint）→ Episodic（agent_run/step）→ Semantic（pgvector，已有）→ Profile（用户确认后生效）。
- **有界执行**：单 Agent，三重上限（steps / tool_calls / llm_calls），永不无限循环。

已完成（2026-08-29）：

- `trip_agent/agent/` 包：约束槽位三态、8 个声明式工具、LangGraph 有界循环、守门机制。
- `worker/processor.py` 编排骨架去重（724 → 664 行）。
- Python 测试 1716 → 1732 passed。

详细路线见 [Agent化路线图](Agent化路线图.md)：

- **Phase 1（必须完成）**：修 V1 级缺陷（LLM 超时击穿 run 等 5 项）、槽位状态机扩展（REJECTED / USER_OVERRIDE）、agent_run/step 轨迹表、AGENT_ASK_USER 事件契约、checkpointer。
- **Phase 2（提升竞争力）**：Agent 接入 AMQP、build_itinerary 工具、critic 节点、前端对话页（聊天 + 卡片）、SSE Agent Trace。
- **Phase 3（高级能力）**：WAITING_USER 可恢复中断、user_travel_profile 长期记忆、planner 策略节点、Copilot 嵌入 Workspace。

## 3. 明确不属于当前主线
